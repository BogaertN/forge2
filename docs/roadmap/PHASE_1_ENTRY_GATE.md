# Phase 1 Entry Gate

Controlling roadmap:

AI.Web Forge 2.0 Production Build Bible — Open-Source-First Non-LLM Self-Constructing Engineering Agent

Entry authority:

**FINAL PHASE 0 ACCEPTANCE**

## Phase 1 objective

Establish immutable core contracts, versioned state
identities, canonical serialization, validation, stable
hashing, and explicit lifecycle states.

## Allowed Phase 1 scope

- versioned immutable contract objects;
- canonical JSON-compatible serialization;
- deterministic identifiers and hashes;
- request and action state identities;
- explicit validation failures;
- schema evolution rules;
- unit and property-oriented invariant tests;
- source-authority and acceptance receipts.

## Not authorized in Phase 1

- terminal execution;
- filesystem mutation outside the build process;
- package acquisition;
- capability discovery;
- natural-language classification;
- machine-learning models;
- planning;
- code construction;
- internet research;
- memory promotion;
- Contribution Economy finalization;
- operator API;
- operator UI;
- deployment;
- self-construction.

## Permanent boundaries

Forge 1 remains read-only.

Forge 2 remains independently runnable.

No LLM receives meaning, planning, tool-selection,
verification, permission, execution, or canonical-memory
authority.

Product capability must not be claimed until its own
roadmap gate passes.
