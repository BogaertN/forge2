# License Decision

Status: PENDING FINAL DECISION OWNER SELECTION

Build 000B does not grant a public open-source license for Forge 2.0.

Until the Decision Owner selects and records a license:

- the repository should remain private;
- all rights remain reserved;
- source may not be redistributed merely because Forge uses
  open-source dependencies;
- copied or adapted upstream code must preserve its own license;
- dependency licenses must be recorded;
- no incompatible code may be admitted.

The open-source-first engineering doctrine governs capability reuse. It
does not automatically determine the license of the Forge 2.0 product.

A final license decision must consider:

- commercial plans;
- contributor agreements;
- patent terms;
- reciprocal-license effects;
- dependency compatibility;
- Contribution Economy design;
- public versus private repository strategy.
