# Forge 2.0 Initial System Boundary

## Established in Build 000B

This repository currently provides only:

- repository identity;
- controlling-roadmap identity;
- an establishment-status package;
- governance documents;
- source-authority evidence;
- tests;
- a CI skeleton.

## Not yet implemented

The following are not product capabilities in Build 000B:

- natural-language interpretation;
- machine-learning classification;
- capability discovery;
- package qualification;
- terminal execution;
- project mutation;
- repository intelligence;
- planning;
- construction;
- verification services;
- candidate memory;
- Contribution Economy integration;
- operator API;
- operator UI;
- public research;
- mathematics;
- simulation;
- self-construction.

## Permanent architectural direction

Future components must communicate through versioned typed contracts.

Entry points must remain thin.

No new monolithic main module is allowed.

User interfaces consume public API contracts rather than importing
mutable Python internals.
